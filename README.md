# CasaLangue

A fictional, French-first landing page for a Casablanca language center. The demo is designed as a sales asset for a local website and WhatsApp lead-capture service.

## Features

- Responsive, mobile-first landing page
- Course, methodology, testimonial, and contact sections
- Direct WhatsApp calls to action
- Registration form that prepares a structured WhatsApp enquiry
- Static Next.js export suitable for Vercel
- Accessible labels and reduced-motion support

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
```

The static build is generated in `out/`.
